# Best of 99

Live companion page for Clash Royale best-of-99 friendly series: score race to 50, ban phases, momentum, highlights, every deck and every game.

- All series: https://tojacob03.github.io/bo99/
- One series: `https://tojacob03.github.io/bo99/?s=<series>`
- Mods add `&mod=<token>` once to enter bans; the browser remembers it.

Results come from the in-game battle log via a Supabase edge function and refresh every 30 seconds while a series is live. Unofficial fan project, not affiliated with Supercell.
